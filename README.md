# Novel Workspace

ส่วนขยาย SillyTavern ที่เปลี่ยน ST ให้เป็นห้องเขียนนิยายเต็มหน้าจอ สำหรับคนที่อยากเขียนเอง แต่ชอบสภาพแวดล้อมของ SillyTavern

## ติดตั้ง

Extensions → Install extension → วางลิงก์

```
https://github.com/ribbinzcat-afk/novel-workspace
```

## เปิดใช้งาน

- ไม้คทา (ข้างช่องพิมพ์) → **Novel Workspace**
- หรือพิมพ์ `/novel`
- หรือปุ่ม "เปิดหน้าเขียนนิยาย" ในหน้า Extensions

## ฟีเจอร์ (v0.1 — MVP)

**เรื่องและตอน**
- หลายเรื่องในที่เดียว สลับได้จากเมนูด้านบน
- แต่ละเรื่องแบ่งเป็นตอน เพิ่ม เลื่อนลำดับ ลบได้

**Treatment**
- ภาพรวมเรื่อง: logline, แนว, premise, ตัวละครหลัก, โลก, โน้ต
- Treatment รายตอน: เรื่องย่อ, ลำดับเหตุการณ์ (บรรทัดละเหตุการณ์), POV, สถานที่, ตัวละคร, hook ท้ายตอน, โน้ต, สถานะ, เป้าจำนวนคำของตอน

**หน้าเขียน**
- รายชื่อตอน (ซ้าย) พร้อมจำนวนคำและแถบความคืบหน้า
- หน้ากระดาษ ปรับฟอนต์ ขนาด ระยะบรรทัด ความกว้างได้ในหน้า Extensions
- Treatment ของตอนที่เขียนอยู่ (ขวา)
- โหมดโฟกัส (Esc เพื่อออก)
- บันทึกอัตโนมัติ + สำรองในเบราว์เซอร์ระหว่างพิมพ์ · Ctrl/Cmd + S บันทึกทันที

**นับคำและสถิติ**
- นับคำภาษาไทยด้วยตัวตัดคำในเบราว์เซอร์ (`Intl.Segmenter`) — ค่าคร่าว ๆ
- เป้าหมายรายวัน + วงแหวนความคืบหน้ามุมบน
- นับคำที่เพิ่มขึ้น **สุทธิ** ต่อวัน (เขียนเพิ่ม − ลบออก) ตั้งเวลาตัดวันได้ (ค่าเริ่มต้นตี 4)
- หน้าสถิติ: วันนี้, จำนวนวันต่อเนื่องที่ถึงเป้า, 7/30 วัน, วันที่เขียนเยอะสุด, กราฟ 30 วัน, วันนี้เขียนตอนไหนไปเท่าไร

## ข้อมูลเก็บที่ไหน

ไฟล์ JSON ในโฟลเดอร์ผู้ใช้ของ ST: `data/<user>/user/files/`

- `novelws-index.json` รายชื่อเรื่อง
- `novelws-project-<id>.json` หนึ่งไฟล์ต่อหนึ่งเรื่อง (ทุกตอน + treatment)
- `novelws-stats.json` สถิติรายวัน

แยกจากแชท การ์ดตัวละคร และ settings.json · สำรองได้ด้วยการก๊อปไฟล์พวกนี้
