# Novel Workspace

ส่วนขยาย SillyTavern ที่เปลี่ยน ST ให้เป็นห้องเขียนนิยายเต็มหน้าจอ สำหรับคนที่อยากเขียนเอง แต่ชอบสภาพแวดล้อมของ SillyTavern

## ติดตั้ง

Extensions → Install extension → วางลิงก์

```
https://github.com/ribbinzcat-afk/novel-workspace
```

## เปิดใช้งาน

- ไม้คทา (ข้างช่องพิมพ์) → **Novel Workspace**
- หรือพิมพ์ `/novel`
- หรือปุ่ม "เปิดหน้าเขียนนิยาย" ในหน้า Extensions

## ฟีเจอร์ (v0.3)

**เรื่องและตอน**
- หลายเรื่องในที่เดียว สลับได้จากเมนูด้านบน
- แต่ละเรื่องแบ่งเป็นตอน — **ลาก** <kbd>⠿</kbd> เพื่อสลับลำดับ (ใช้ได้ทั้งเมาส์และนิ้ว)

**Treatment**
- ภาพรวมเรื่อง: logline, แนว, premise, ตัวละครหลัก, โลก, โน้ต
- ปุ่ม **ดึงจาก ST** ที่ช่องตัวละครหลักและโลก: เลือกการ์ดตัวละครหรือรายการใน Lorebook มาต่อท้ายได้
- Treatment รายตอน: เรื่องย่อ, ลำดับเหตุการณ์, POV, สถานที่, ตัวละคร, hook ท้ายตอน, โน้ต, สถานะ, เป้าจำนวนคำของตอน
- ลำดับเหตุการณ์เป็นรายการแยกข้อ: Enter = เพิ่มข้อถัดไป, Backspace ในช่องว่าง = ลบ, ลากสลับได้, วางข้อความหลายบรรทัดจะแตกเป็นหลายข้อให้เอง
- **Corkboard**: ดูทุกตอนเป็นการ์ด (สีขอบบนตามสถานะ) ลากสลับลำดับได้ กดการ์ดเพื่อเปิด Treatment ของตอนนั้น

**หน้าเขียน**
- รายชื่อตอน (ซ้าย) พร้อมจำนวนคำและแถบความคืบหน้า
- หน้ากระดาษ ปรับฟอนต์ ขนาด ระยะบรรทัด ความกว้างได้ในหน้า Extensions
- แผงขวามี 2 แท็บ: Treatment ของตอนนี้ / **เวอร์ชัน**
- โหมดโฟกัส (Esc เพื่อออก)
- บันทึกอัตโนมัติ + สำรองในเบราว์เซอร์ระหว่างพิมพ์ · Ctrl/Cmd + S บันทึกทันที

**เวอร์ชัน (snapshot)**
- เก็บอัตโนมัติวันละครั้ง ก่อนเริ่มแก้ตอนนั้น (เก็บไว้ 14 อันล่าสุดต่อตอน)
- ปุ่มกล้อง = บันทึกเวอร์ชันเองพร้อมตั้งชื่อ (เก็บได้ 50 อันต่อตอน)
- ดู / กู้คืน / ลบ — กู้คืนแล้วข้อความเดิมจะถูกเก็บเป็นเวอร์ชัน “ก่อนกู้คืน” ให้ย้อนกลับได้

**นับคำและสถิติ**
- นับคำภาษาไทยด้วยตัวตัดคำในเบราว์เซอร์ (`Intl.Segmenter`) — ค่าคร่าว ๆ
- เป้าหมายรายวัน + วงแหวนความคืบหน้ามุมบน
- นับคำที่เพิ่มขึ้น **สุทธิ** ต่อวัน (เขียนเพิ่ม − ลบออก) ตั้งเวลาตัดวันได้ (ค่าเริ่มต้นตี 4)
- หน้าสถิติ: วันนี้, จำนวนวันต่อเนื่องที่ถึงเป้า, 7/30 วัน, วันที่เขียนเยอะสุด, **ปฏิทิน heatmap 26 สัปดาห์**, กราฟ 30 วัน, วันนี้เขียนตอนไหนไปเท่าไร

**ส่งออก** (แท็บ “ส่งออก”)
- เลือกตอนที่จะส่งออก (ทั้งหมด / บางตอน / เฉพาะที่เสร็จหรือเผยแพร่แล้ว)
- Word (.docx), Markdown (.md), ข้อความ (.txt)
- ตั้งรูปแบบหัวตอนเองได้ (`{n}` = เลขตอน, `{title}` = ชื่อตอน), ใส่ชื่อเรื่องหน้าแรก
- .docx: ขึ้นหน้าใหม่ทุกตอน, ย่อหน้าบรรทัดแรก, เลือกฟอนต์และขนาด (ค่าเริ่มต้น TH Sarabun New 16pt), หัวตอนเป็น Heading 1 จึงใช้ Navigation Pane ของ Word ได้
- ส่งออก Treatment เป็นเอกสารแยกได้ด้วย

**ผู้ช่วย AI** (ปิดไว้เป็นค่าเริ่มต้น — เปิดในหน้า Extensions)
- แท็บ AI ในแผงขวาของหน้าเขียน: วิจารณ์ฉาก · เช็กความต่อเนื่องกับ Treatment · ตอนนี้ตรงเป้าไหม · หาคำ/สำนวนอื่น · ถามเอง
- AI ให้ความเห็นเท่านั้น ไม่เขียนหรือแก้ต้นฉบับแทน
- เลือกข้อความก่อนกด = ใช้เฉพาะส่วนนั้น, ไม่เลือก = ทั้งตอน
- เห็นจำนวน token (นับด้วย tokenizer ของ ST) ก่อนกดส่งทุกครั้ง และเห็นยอดที่ส่ง/ตอบกลับในผลลัพธ์
- เลือก Connection Profile แยกได้ (ไม่แนบ preset โรลเพลย์) ไม่เลือก = API หลักของ ST แบบไม่แนบการ์ดหรือแชท
- แก้ prompt ทุกตัวได้ พร้อมปุ่มคืนค่าเริ่มต้น และเตือนเมื่อตัวแปรที่จำเป็นหายไป

## ข้อมูลเก็บที่ไหน

ไฟล์ JSON ในโฟลเดอร์ผู้ใช้ของ ST: `data/<user>/user/files/`

- `novelws-index.json` รายชื่อเรื่อง
- `novelws-project-<id>.json` หนึ่งไฟล์ต่อหนึ่งเรื่อง (ทุกตอน + treatment)
- `novelws-snaps-<id>.json` ประวัติเวอร์ชันของเรื่องนั้น
- `novelws-stats.json` สถิติรายวัน

แยกจากแชท การ์ดตัวละคร และ settings.json · สำรองได้ด้วยการก๊อปไฟล์พวกนี้
